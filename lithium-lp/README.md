## 編集と出力

このディレクトリの `index.html`、`styles.css`、`app.js` を編集後、プロジェクトルートで `python3 build_lithium_lp.py` を実行する。新ページだけを `dist/lithium/` へ出力する。既存ビルダーの実行は不要。

生成画像は `dist/lithium/assets/camp-lights-on.png` と `camp-lights-off.png`。元画像・プロンプト・生成方法は `generation.json` に保存。新ページは必要な既存画像も専用assetsへコピーしているため、旧ページのスタイルや動作には依存しない。

## 演出

- 最初に電気が消えた夜のキャンプ場を表示し、読み込み後に照明がともる。スイッチで再度切り替え可能。
- FVは「旅先の電気に、もっとゆとりを。」を3段の文字組みで表示。太いゴシック・明朝体・大きな色付きの「ゆとり」と、濃い帯の補足文で強弱をつける。文字サイズはメイン画像の幅に連動し、スマホでも同じバランスを保つ。
- 「ゆとり」は3文字が少しずつずれて立ち上がり、その後は約5.4秒周期でふわっと上下する。表示中の文字は消さず、画面外・非表示タブではループを一時停止。動きを減らす端末設定では静止表示。
- 見出しの段階表示、スクロールでの文章・図の表示、短い横流れの帯、電池の充電表示。
- 電源図が画面に入ると、3つの充電経路の点線が流れ、電池が左から3段階で満たされる。満充電の光から家電への流れまで約6.4秒で繰り返す。画面外・非表示タブでは一時停止し、戻ると続きから再生。「一時停止／再生」ボタンでも切り替え可能。動きを減らす端末設定では満充電の静止図を表示。
- 充電経路の見出しには、走行中・自宅の外部電源・屋根のソーラーパネルを示す背景透過イラストを配置。生成条件と保存先は `charging-illustrations.json` に記録。
- 動きを減らす端末設定では、点灯済み・静止表示を基本とする。見出しなどの登場演出は短く一度のみ。
- 食事・くつろぎ・連泊の3枚を、中央が大きく左右が小さいカードスライドで表示。約5秒ごとに横へ進み、最後から最初へも同じ方向につながる。スワイプ・左右矢印・丸ボタン・矢印キー・Home/Endキーで操作可能。
- カードが画面に出ているときだけ自動切り替え。スワイプ・矢印・丸ボタンで手動操作したあとも、約5秒後に自動切り替えを再開する。キーボードで操作中は読みやすさのため一時停止し、フォーカスを外すと再開。停止ボタンで明示的に止めた場合は再生まで停止を保つ。動きを減らす端末設定では自動切り替えも行わない。JavaScriptなしでは3枚を縦に表示。
- 細い漫画線と淡い塗りの既存トーンを継承。参考サイトの素材やソースはコピーしていない。
