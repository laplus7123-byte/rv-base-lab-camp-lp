## 編集と出力

このディレクトリの `index.html`、`styles.css`、`app.js` を編集後、プロジェクトルートで `python3 build_lithium_lp.py` を実行する。新ページだけを `dist/lithium/` へ出力する。既存ビルダーの実行は不要。

生成画像は `dist/lithium/assets/camp-lights-on.png` と `camp-lights-off.png`。元画像・プロンプト・生成方法は `generation.json` に保存。新ページは必要な既存画像も専用assetsへコピーしているため、旧ページのスタイルや動作には依存しない。

## 演出

- 最初に電気が消えた夜のキャンプ場を表示し、読み込み後に照明がともる。スイッチで再度切り替え可能。
- FVイラストの左下に「関東運輸局長認証／自動車特定整備事業／第3-5923号」を3段で記載したバッジを配置。クリーム色・緑・茶色で統一し、文字は画像にせずHTMLで表示。
- FVは「旅先の電気に、もっとゆとりを。」を3段の文字組みで表示。太いゴシック・明朝体・大きな色付きの「ゆとり」と、濃い帯の補足文で強弱をつける。文字サイズはメイン画像の幅に連動し、スマホでも同じバランスを保つ。
- FVの見出しは行ごとに下から現れ、「ゆとり」の中を金色〜クリーム色の光が左から右へ流れる。約5秒周期で繰り返し、文字の位置・大きさは固定。画面外・非表示タブではループを一時停止。動きを減らす端末設定、ハイコントラスト表示、JavaScriptなしでは通常の文字色で静止表示。
- 見出しの段階表示、スクロールでの文章・図の表示、電池の充電表示。
- FVの次は「旅先で、したいこと」へ直接つながる構成。道路風のアニメーション帯は削除。
- 電源図の締めの「リチウムイオンに替えて、旅の時間を、もっと豊かに。」は最大26pxの太字2行で大きく表示。スマホの幅に合わせて縮小する。
- 締めの文章は電池と同じゴールドとクリーム色の白を、3.2秒周期でなめらかに往復。文字の位置・サイズ・不透明度は保ち、電源図と同じ条件で画面外・非表示タブでは一時停止。動きを減らす端末設定では白の静止表示。
- スマホ・タブレット幅では、電話・LINEの問い合わせボタンを最初の画面から下部に固定。画面下の安全領域と末尾の余白を確保し、最後までボタンが見える。PC幅では従来どおり途中のセクションで表示。
- 店舗情報の住所の下にGoogleマップを埋め込み。既存の修理LPと同じ所在地を表示し、画面幅に合わせた250〜310pxの高さで表示。Googleマップで場所・経路を確認するリンクも配置。
- 電源図が画面に入ると、3つの充電経路の点線が流れ、電池が左から3段階で満たされる。満充電の光から家電への流れまで約6.4秒で繰り返す。画面外・非表示タブでは一時停止し、戻ると続きから再生。動きを減らす端末設定では満充電の静止図を表示。
- 充電経路の見出しには、走行中・自宅の外部電源・屋根のソーラーパネルを示す背景透過イラストを配置。生成条件と保存先は `charging-illustrations.json` に記録。
- 動きを減らす端末設定では、点灯済み・静止表示を基本とする。見出しなどの登場演出は短く一度のみ。
- 食事・くつろぎ・連泊の3枚を、中央が大きく左右が小さいカードスライドで表示。約5秒ごとに横へ進み、最後から最初へも同じ方向につながる。スワイプ・左右矢印・丸ボタン・矢印キー・Home/Endキーで操作可能。
- スライド幅は表示領域の70%。3枚とも画像を少し横長にし、見出し・番号・余白を抑えたコンパクトなサイズで統一。本文は14pxを維持する。
- カードが画面に出ているときだけ自動切り替え。スワイプ・矢印・丸ボタンで手動操作したあとも、約5秒後に自動切り替えを再開する。キーボードで操作中は読みやすさのため一時停止し、フォーカスを外すと再開。停止ボタンで明示的に止めた場合は再生まで停止を保つ。動きを減らす端末設定では自動切り替えも行わない。JavaScriptなしでは3枚を縦に表示。
- 細い漫画線と淡い塗りの既存トーンを継承。参考サイトの素材やソースはコピーしていない。

## 2026-11-06 デザイン調整

- ページ外側・FV周囲・各セクションは無地。クリーム色・緑・茶色を中心に、濃い色の枠で区切って構成。
- 本文はNoto Sans JPの500、主見出しは900。要所だけNoto Serif JPを組み合わせ、見出し・数字・本文に強弱をつける。
- 画面中央の幅は480pxを維持し、スマホでは画面幅に合わせて文字と図を縮小。
